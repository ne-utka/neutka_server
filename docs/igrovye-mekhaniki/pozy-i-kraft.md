# Позы и визуальный крафт

## Позы игрока

* `[` — лечь или перейти в ползание;
* `]` — сесть;
* `Shift` — выйти из текущей позы;
* движение прерывает сидение;
* лёжа можно продолжать ползти.

Из сидения можно сразу перейти в лежание и наоборот. Для работы данных клавиш необходим мод Clientizen.

## Предметы на верстаке

Когда игрок раскладывает рецепт в верстаке, окружающие видят предметы прямо на его поверхности — по сетке 3×3 и в правильной ориентации относительно мастера.

Если один верстак одновременно откроют несколько игроков, визуализация закрепляется за первым. Это предотвращает наложение разных рецептов: наблюдатели увидят только его крафт.

## Предметы на наковальне

Два входных предмета также физически отображаются на поверхности наковальни. Они лежат по центру с небольшим промежутком и ориентированы относительно игрока, который работает с блоком. Результат операции не показывается.

Сам мастер продолжает видеть обычный интерфейс без лишних моделей, а окружающие — разложенные предметы. Если наковальню одновременно используют несколько игроков, визуализация закрепляется за первым до закрытия интерфейса.
