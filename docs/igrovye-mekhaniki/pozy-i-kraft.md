# Позы и визуальный крафт

## Позы игрока

* `[` — лечь или перейти в ползание;
* `]` — сесть;
* `Shift` — выйти из текущей позы;
* движение прерывает сидение;
* лёжа можно продолжать ползти.

Из сидения можно сразу перейти в лежание и наоборот. Для работы данных клавиш необходим мод Clientizen.

## Предметы на верстаке

Когда игрок раскладывает рецепт в верстаке, окружающие видят предметы прямо на его поверхности — по сетке 3×3 и в правильной ориентации относительно мастера.
