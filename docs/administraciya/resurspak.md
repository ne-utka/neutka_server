# Ресурспак и новый контент

Исходники ресурспака находятся в `resourcepack/source`, готовый архив — в `resourcepack/dist/neutka.zip`.

## Новый плакат

1. Подготовь текстуру в том же формате и размере, что существующие плакаты.
2. Добавь её и связанные модельные файлы в namespace `marallyzen`, используя уникальное имя латиницей.
3. Собери и установи новую версию ресурспака.
4. Создай плакат командой `/poster spawn <asset_name>`.

Имя в команде должно точно совпадать с именем зарегистрированного ассета.

## Новая запись диктофона

1. Конвертируй аудио в `.ogg`.
2. Положи файл в `assets/marallyzen/sounds`.
3. Зарегистрируй звуковое событие в `assets/marallyzen/sounds.json`.
4. Добавь ключ и точную длительность записи в конфигурацию `dictaphone.dsc`.
5. При необходимости добавь наррацию командой `/dictaphone narration ...`.
6. Создай устройство: `/dictaphone spawn <audio_file>`.

Не добавляй расширение `.ogg` в игровую команду.

## Публикация обновления

После любых изменений:

1. пересобери `neutka.zip` без лишней внешней папки;
2. загрузи архив на постоянный HTTPS-хост;
3. вычисли SHA-1 именно загруженного файла;
4. обнови `resource-pack`, `resource-pack-sha1` и `resource-pack-id` в `server.properties`;
5. перезапусти сервер и проверь чистое подключение клиента.

Если содержимое архива изменилось, старый SHA-1 использовать нельзя.
